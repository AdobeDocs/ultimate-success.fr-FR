# Mise en œuvre d’Adobe Data Insights Agent dans CJA

Découvrez comment transformer Adobe Data Insights Agent en un workflow pratique et quotidien dans Customer Journey Analytics. Cette session montre comment les équipes peuvent utiliser l’invite en langage naturel pour accélérer l’analyse, activer les informations en libre-service et réduire la dépendance aux rapports manuels. Si vous souhaitez améliorer le délai de mise en œuvre d’insight et adapter la prise de décision basée sur les données à l’échelle de votre entreprise, faites attention.
