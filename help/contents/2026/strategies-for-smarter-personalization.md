# Expériences basées sur du code AJO : stratégies pour une personnalisation plus intelligente

Découvrez les bonnes pratiques relatives à la conception, à l’implémentation et à l’optimisation des expériences basées sur le code Adobe Journey Optimizer. Ce webinaire présente des conseils pratiques pour créer des expériences personnalisées et évolutives, éviter les défis d’implémentation courants et optimiser la valeur de la personnalisation basée sur le code sur les points de contact numériques.

>[!VIDEO](https://video.tv.adobe.com/v/3504248/?learn=on&enablevpops)

## Ce Que Vous Apprendrez

- **Bonnes pratiques** : découvrez comment concevoir et implémenter des expériences basées sur du code évolutif.
- **Surmonter les défis** : comprendre les problèmes courants et les stratégies pour les éviter.
- **Maximiser l’impact** : découvrez des méthodes pour optimiser la valeur de la personnalisation basée sur le code à travers différents points de contact numériques.

## Public Cible

- **Administrateurs** : des informations sur la gestion et le déploiement efficaces de la personnalisation basée sur le code.
- **Développeurs** : directives techniques pour la création de modèles d’implémentation évolutifs et réutilisables.
- **Utilisateurs** : comprendre comment les expériences basées sur du code améliorent l’engagement client.
